# Gargantua Visual Reference

UCC reference role: use the Gargantua/black-hole material as a visual seriousness target, not as an instruction to turn Universal Command Center into a Schwarzschild raytracer.

Useful qualities to borrow:
- a focal object with gravity and presence
- luminous atmosphere/ring structures
- fine particle density
- asymmetric cinematic lighting
- deep shadow contrast
- smooth camera motion
- restrained instrument-panel HUD

Do not import the full Gargantua implementation plan into UCC:
- no standalone black-hole simulator
- no npm/build rewrite
- no dedicated GLSL raytracer milestone inside the Command Center shell
- no unrelated audio/cinematic control stack

Desired UCC fusion:

Codex realism + Claude spatial ecosystem + Kimi cinematic quality

Visual progression:

Cosmos -> focused space planet -> living floating world -> cutaway/explode -> ARCH -> scoped Codex work packet

At planet/world scope, modules should read as floating landmasses, stations, moons, conduits, and activity streams generated from canonical metadata. The outer world can borrow cinematic ring/atmosphere language from the reference images, but relationships and modules must remain data-driven.
